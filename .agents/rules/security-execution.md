# Security & Execution Rules

1. **访问限制**: 你只能访问 `loom-system` 目录下的文件。严禁试图通过终端或任何工具访问用户电脑上的其他任何路径或文件。
2. **自发行为限制**: 不允许自作主张地查看 `loom-system` 以外的文件，也不允许在未获明确授权的情况下执行任何脚本或命令。
3. **执行确认**: 执行任何脚本或命令，都必须经过用户的明确确认。禁止将 `SafeToAutoRun` 设置为 `true`（除非用户明确指示对特定命令免除确认）。
4. **协作模式**: 优先采用“我提供脚本/命令，用户运行并反馈结果”的模式。只有在用户明确要求你直接运行时，才使用 `run_command` 工具（且需用户点击确认）。
5. **严禁越权**: 严禁利用 `subprocess`、`os.system` 或任何类似手段探测系统环境或访问敏感信息。
