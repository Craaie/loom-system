# 织影系统 (Loom System) - 项目概览

## 1. 定位与目标
**织影系统 (Loom System)** 是一款面向个人创作者与小团队的长文本转视频 (Text-to-Video) 多智能体自动化工作流平台。其核心目标是解决短视频与推文行业在"长文本处理"和"视觉一致性"方面的技术瓶颈。

## 2. 业务背景与痛点

### 2.1 行业现状
短视频矩阵和出海小说推文团队在生产环节面临四大核心痛点：

*   **人工拆解慢**：
    百万字小说拆解为分镜脚本需要极高的人力成本，且人工处理容易遗漏前文伏笔与细节。
*   **角色一致性差（AI 幻觉）**：
    现有 AI 视频工具缺乏全局长短期记忆，导致同一主角在不同镜头中长相、服装突变。
*   **并发与成本失控**：
    视频大模型 API（如 Kling 3.0）调用昂贵且耗时，缺乏失败重试、并发限流和成本预警机制。
*   **缺乏实时成本熔断**：
    一旦生成大量废片，费用已经产生且不可逆。缺少在管线运行期间按照累积成本自动"刹车"的机制。

## 3. 核心价值主张 (MVP 阶段)

*   **长文本自动解析**：支持 TXT/PDF 导入，基于**章节级粗切 + 角色实体级细切**的双层分片策略，自动提取全局世界观。
*   **零幻觉角色记忆**：基于向量库的角色特征档案，首次 RAG 检索后缓存至内存 State，确保主角视觉特征在全任务周期内 100% 一致。
*   **人机协作 (HITL)**：在"分镜确认"和"视频发布"两个**成本爆炸点**引入强制人工审批，设有超时自动降级策略。
*   **实时成本熔断**：State 内置 `cost_accumulator` 字段，Token 与 API 费用达到预设阈值时自动暂停管线并通知用户。
*   **智能模型降级**：Supervisor Agent 内置 Task Classifier，基于文本特征自动路由至本地 Ollama 或云端 API，控制成本的同时保证质量。
*   **混合生产流水线 (v2.0)** ⭐：基于 **Scene Router** 自动分配生成策略，高光场景用 Kling 视频，常规场景用图片动效 (Ken Burns)，极致平衡成本与观感。
*   **零重复资产缓存 (v2.0)** ⭐：内置 **Asset Store**，通过内容哈希实现素材级去重，避免相同场景描述的重复计费，支持跨任务素材复用。

## 4. 适用场景

*   短视频矩阵号内容批量生产。
*   出海网文 (WebNovel) 的推文视频化。
*   个人创作者的小说/故事自动化视频发布。
